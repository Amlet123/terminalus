# Эмулятор оболочки (вариант 5)

Практическая работа по дисциплине «Конфигурационное управление».
Текущий этап: **1. REPL**.

## 1. Общее описание

Консольный (CLI) эмулятор оболочки UNIX-подобной ОС, написанный на Python.
Работает в цикле «прочитать строку, выполнить, вывести результат» (REPL).

На этапе 1 реализовано:

- приглашение к вводу вида `(vfs) username@hostname:~$`: оно содержит имя VFS,
  а имя пользователя и хоста берутся из реальной ОС;
- парсер, который раскрывает переменные окружения реальной ОС
  (`$HOME`, `${HOME}`) и делит строку на команду и аргументы по пробелам;
- приветствие при запуске со списком доступных команд;
- сообщения об ошибках (неизвестная команда, неверные аргументы);
- команды-заглушки `ls` и `cd`, команда `exit`.

Виртуальная файловая система, параметры командной строки и остальные команды
появятся на следующих этапах.

## 2. Описание функций и настроек

### Команды

| Команда        | Описание                                                          |
|----------------|-------------------------------------------------------------------|
| `ls [арг...]`  | Заглушка: печатает своё имя и список аргументов                   |
| `cd [арг]`     | Заглушка: печатает своё имя и аргументы. Больше одного аргумента — ошибка |
| `exit`         | Завершает работу эмулятора. С аргументами — ошибка                |

Пустая строка игнорируется. `Ctrl+D` и `Ctrl+C` тоже завершают работу.

### Ошибки

| Ситуация                 | Сообщение                                   |
|--------------------------|---------------------------------------------|
| Неизвестная команда      | `Ошибка: неизвестная команда 'foo'`         |
| `cd` с двумя и более аргументами | `Ошибка: cd: слишком много аргументов` |
| `exit` с аргументами     | `Ошибка: exit: команда не принимает аргументов` |

### Раскрытие переменных окружения

Переменные раскрываются до разбиения на слова, поэтому значение с пробелами
превращается в несколько аргументов. Неопределённая переменная остаётся
в строке без изменений (`$NOPE` → `$NOPE`).

### Настройки

На этапе 1 параметров командной строки нет. Имя VFS задано константой
`VFS_NAME` в `src/terminalus.py`.

## 3. Сборка и запуск тестов

Нужен Python 3.9 или новее. Внешних зависимостей нет, сборка не требуется.

```
make run     # запуск эмулятора (то же, что python3 src/terminalus.py)
make test    # запуск тестов (то же, что python3 -m unittest discover -s tests -t . -v)
make lint    # проверка стиля, нужен flake8 (pip install flake8)
```

Без `make`:

```
python3 src/terminalus.py
python3 -m unittest discover -s tests -t . -v
```

## 4. Примеры использования

Пример сессии (`student@pc` — пользователь и хост реальной ОС,
`HOME=/home/student`):

```
Эмулятор запущен под учётной записью student@pc
Доступные команды: ls, cd, exit

(vfs) student@pc:~$ ls
[заглушка] команда: ls
[заглушка] аргументы: []
(vfs) student@pc:~$ ls -l /tmp
[заглушка] команда: ls
[заглушка] аргументы: ['-l', '/tmp']
(vfs) student@pc:~$ cd $HOME
[заглушка] команда: cd
[заглушка] аргументы: ['/home/student']
(vfs) student@pc:~$ cd a b
Ошибка: cd: слишком много аргументов
(vfs) student@pc:~$ foo
Ошибка: неизвестная команда 'foo'
(vfs) student@pc:~$ exit now
Ошибка: exit: команда не принимает аргументов
(vfs) student@pc:~$ 
(vfs) student@pc:~$ exit
Завершение работы эмулятора.
```
